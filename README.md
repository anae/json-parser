# JSON Parser

Un utilitaire minimaliste pour valider, indenter et copier du JSON en quelques secondes.

[Voir la démo](https://jsonparser.ananaba.be) · [Découvrir la Toolbox](https://ananaba.be/applications/)

![Aperçu de JSON Parser](https://ananaba.be/assets/app-jsonparser.png)

## Fonctionnalités

- validation immédiate avec message d'erreur lisible ;
- indentation à 2 espaces, 4 espaces ou tabulation ;
- copie du résultat formaté en un clic ;
- raccourci `Cmd/Ctrl + Enter` ;
- interface responsive et accessible.

## Lancer le projet

```bash
docker compose up -d --build
```

Puis ouvrir `http://127.0.0.1:8787`.

## Stack

HTML, CSS et JavaScript sans dépendance, servis par Nginx dans Docker.
